# Défi -- assistant mails pour une formation couture en ligne

## Énoncé

Client fictif (David Ruggieri, exercice hebdomadaire Alegria) : Nadia vend une formation de couture en ligne pour débutantes et reçoit une trentaine de mails par semaine avec toujours les mêmes questions. Elle veut un assistant qui réponde à sa place, mais qui ne dise QUE ce qui est vrai -- une IA testée avant a promis un remboursement à tort.

À faire : trouver le meilleur outil, écrire les consignes de l'assistant, le tester avec au moins 3 questions dont une sans réponse dans les infos fournies. Compte rendu en captures d'écran, pas de .docx.

## Livrables

-> `ATTENDUS.md` -- grille des attendus + écarts assumés

-> `CONSIGNES.md` -- outil choisi (Projet Claude / GPT personnalisé), justification, instructions prêtes à coller, résumé du test

-> `MESSAGES-DISCORD.md` -- Message 1 (livrable noté, fil du projet) + annexe des 3 échanges de test bruts

-> `captures/` -- vide pour l'instant, captures réelles à ajouter par David après reproduction de la configuration dans son compte

## Captures attendues

Deux captures minimum une fois le Projet Claude (ou GPT) créé par David :
1- les instructions collées dans le Projet
2- la conversation de test (au moins la question 2, celle qui refuse le remboursement)
