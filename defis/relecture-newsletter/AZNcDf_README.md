# Projet « La relecture qui réécrit tout »

Défi de type texte (`prompt`) : aucun outil, aucune base, aucun déploiement. Livrable : une liste d'erreurs, un prompt corrigé et sa preuve mesurée.

-> `ATTENDUS.md` : grille des attendus, protocole de preuve, écarts assumés (interne)

-> `MESSAGES-DISCORD.md` : les 3 messages à poster dans le fil et les sorties brutes des 3 exécutions

-> `DIAGNOSTIC.md` : grille d'audit réutilisable, anonymisée
